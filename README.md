# MENTORX — Adaptive Learning Intelligence

An ML-powered adaptive learning platform for college CS subjects. It estimates each student's concept mastery from their real attempts and uses those predictions to pick questions, build learning paths and schedule revision.

**Status:** planning. See [docs/PROJECT_PLAN.md](docs/PROJECT_PLAN.md) for the feasibility analysis, MVP scope, architecture, database schema, ML methodology, roadmap and timeline.

Stack: React + Vite + Tailwind · FastAPI · PostgreSQL · scikit-learn / XGBoost / BKT
